# Mirante modules

The first-party modules of [Mirante](https://github.com/rrgmc/mirante), a personal desktop dashboard. Each folder holds one module, with its own README.

This repository is part of the trial of custom builds. It is not usable yet, and `mirante` stays the official app. The core and the design documents are in [`mirante-core`](https://github.com/rrgmc/mirante-core), and [`mirante-app`](https://github.com/rrgmc/mirante-app) builds them together.

| Module | What it provides |
|---|---|
| [Claude](claude/README.md) | Claude sessions on claude.ai |
| [Documents](document/README.md) | Markdown, text and PDF files |
| [Folder](folder/README.md) | A project's folder, with its Git state and shortcuts to a terminal and an editor |
| [GitHub](github/README.md) | github.com or GitHub Enterprise Server |
| [GitLab](gitlab/README.md) | A GitLab server |
| [Image](image/README.md) | Screenshots or diagrams, with an optional link and memo |
| [Jira](jira/README.md) | A Jira site |
| [Notes](notes/README.md) | Markdown notes, kept in the task's file |
| [Web](web/README.md) | Any web page |
